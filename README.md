## The line

> My fridge's touchscreen now runs ads for the yogurt it watched me throw away, upselling me my own leftovers like a waiter with a grudge.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` and refuses to write
anything longer than 160 characters or spanning more than one line.
No network, no secrets, no files read from outside this repository --
the line is a constant in `main.py`, so every run is deterministic.
